## Procedimiento para utilizar Visual Studio Code

1. Descargar Visual Studio Code.
2. Instalar el programa en la computadora.
3. Abrir Visual Studio Code.
4. Seleccionar la opción Abrir carpeta.
5. Crear un archivo nuevo.
6. Escribir el código correspondiente.
7. Guardar los cambios realizados.
